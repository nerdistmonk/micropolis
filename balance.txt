MICROPOLIS BALANCE NOTES (devworks)
====================================

Status
------
- Repo core is unchanged from stock. Nothing in this file has been applied to the game.
- All economy experiments live in a scratch harness outside the repo (/root/mp-scratch/la/).
- The "LA" city is a procedural map (GenerateSomeCity(12345), then ClearMap()), not real Los Angeles.
- Goal not met: no run reached 50,000 citizens. Best runs reach about 16k to 21k at year 25.

Harness
-------
- Builder: /root/mp-scratch/la/builder_res2.c (4 landfills with road-only reserved strips,
  fire and police every 30 cells, early hospitals every 20 cells).
- Seeded from the SIMSEED env var after ClearMap(). GenerateMap otherwise reseeds from the
  wall clock (core/s_gen.c:117), which made identical binaries diverge.
- Build (example, tiered variant):
    cd /root/mp-scratch/la
    OBJS=$(ls /root/micropolis/build/CMakeFiles/micropolis_sdl3.dir/core/*.o | grep -v "/s_sim\.c\.o\|/s_landfill\.c\.o")
    gcc -O2 -std=gnu11 -Wall -Wno-unused-function -I/root/micropolis/core/headers \
        -o builder_tier builder_res2.c s_sim_tier.o s_landfill_tier.o $OBJS -lm
- Run:
    SIMSEED=1 SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy ./builder_tier 25

Changes in effect (scratch only)
--------------------------------
1. Tax rates (core/s_sim.c:630, 637)
   - FLevels {3.0, 2.5, 2.0}   (stock {1.4, 1.2, 0.8})
   - Tax divisor /60            (stock /120)
2. Service costs: flat x100 per building (stock). Population scaling was tried and removed.
3. Roads: stock upkeep (CalcRoadFund, core/s_sim.c:618-622). Not scaled.
4. Landfill storage: LANDFILL_STAGE_CAP 800 (stock 400), so a block holds 2,400 (stock 1,200).
5. Landfill cost is tiered by block fill (scratch: s_landfill_tier.c LandfillTieredCost,
   used in s_sim_tier.c CollectTax):
   - empty block: 0
   - 1/3 to 2/3 full range: 33 / 66 per block
   - full: 100 per block
6. Health: stock 80/20 residential penalty (core/s_health.c:14-15).
   A 95/5 test changed tax by 0 to 7 a year, so it is not a useful lever.

Earlier comparisons (stock landfill unless noted)
- Stock economy, stock landfill: population peaks ~14k, collapses to 2-6k by year 25.
- Stock economy, 2x landfill: holds 11-14k at year 25, cash negative.
- Scaled services + FLevels + /60 (not in effect): population ~18k, cash negative from year 17.

Failure mode (all variants)
---------------------------
- The city ends with 4 landfill blocks. Garbage starts accumulating around year 18-20.
- Land value falls (about 64 to 37), which cuts tax income by roughly half.
- Expansion needs a clear 3x3 patch beside a full block. The packed map has none after year 18.
  This is not yet confirmed in code.
- Fix options not yet tested: reserve more landfill space at the start, or raise capacity further.

Known gaps
----------
- Only four seeds, 25 years, GameLevel 0 (easy).
- Map is procedural, so zone counts are fixed at about 58 to 91 cells.
- The reload gap (5,560 vs 5,700) is unexplained.
- Balance changes are not proposed for the core. Any change needs review first.
